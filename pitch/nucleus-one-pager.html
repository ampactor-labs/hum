The problem

Software that steers physical things (inverters, flywheels, flight controls) is tested, reviewed and hoped on: no mainstream language lets a team state "this loop never reaches the network, never allocates, never commands past this bound" and have the compiler prove it. Coding agents now write that software, and the grid is where the gap bites first: every new inverter is a software product under UL 1741 SB, and Utah's data centers are the load.

What exists today

Mentl is a programming language and self-hosting compiler with an algebraic effect system, compiled to WebAssembly. A negated effect such as !Network is a claim proven through every call or the program does not build; every fact carries its reason; a learning rule is derived from the chain it learns on. The pinned compiler reproduces itself byte for byte. [[how long]] of work, open source (Apache and MIT). Beside it, sonido: a Rust DSP framework whose kernels run unchanged in plugins, a browser editor and a guitar pedal.
