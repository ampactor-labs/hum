Appendix

The trusted base

  • The compiler is written in Mentl and the pinned binary reproduces itself byte for byte; that fixed point is the release.
  • The verifier is sound for what it decides and incomplete by design: a claim it cannot decide is reported as pending, never silently passed.
  • One false proof is known and documented: a recursion deep enough to exhaust the stack traps although its function says it cannot.
  • Rust prevents memory bugs, not effects; Simulink and SCADE verify models and generate C. Neither states "never reaches the network" as an obligation through every callee, proves a function allocation-free, or derives a learning rule from the chain.
Mentl · appendixsoundness
Appendix

Running on a controller

  • The proof is at compile time. The artifact is one WebAssembly module importing WASI and nothing else.
  • It runs wherever wasmtime runs, which includes the Linux supervisors that sit beside inverters today; the demo's controller runs that way.
  • A native backend is on the roadmap; the pedal in the demo runs the ear natively on a Cortex-M7 today.
  • The learner and the predictor keep learning inside a loop proven not to allocate: learning at the edge that cannot stall.

Appendix

Durable computation

A running controller is a value: persisted by copying its image mid-stream and resumed with mentl resume, continuing from the same tick with the same state of charge. The recording is in the repository; the limits are stated there too.

When the grid goes dark, the computation does not.
