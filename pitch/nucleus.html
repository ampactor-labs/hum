The hard tech

Mentl proves what software can never do.

You write a rule into the code, such as "this never touches the internet" or "this never writes a file".

The compiler checks the rule through every function the code calls. Break it, and the program won't build.

Seven months and 2,600 commits since March. The compiler is written in Mentl and compiles itself. Open source: github.com/ampactor-labs/mentl

What is proven, exactly

The controller's ruleStatus
No network, file, clock or other call outside the program while it decidesProven by the compiler through every call
No memory allocated while it decidesProven
The flywheel within 100 kW, the battery within 300 kWProven: each machine answers a command with a power inside its rating, and the compiler checks the answer
It never stops with an errorProven for every function the controller defines; one byte-range check inside the library's print routine is not proven yet
Its decisions are goodTested on recordings, not proven

The compiler is written in Mentl, and the pinned binary rebuilds itself byte for byte. The first four rows are checked through every call, and a copy that breaks one does not build.
