How it works

The power grid's frequency shows whether it has enough power. A guitar can hear it.

The gridThe whole Western grid, from Alberta to Baja, runs at one frequency: 60 hertz. When demand outruns supply, the frequency falls.
The earEvery power adapter hums at that frequency. A guitar pickup resting on one hears it, and my audio library, sonido, measures it to a thousandth of a hertz.
The StationA model of a Torus Station: a flywheel for the first seconds (100 kW for six minutes) and a battery for the hours (300 kW for four hours). Simulated.
The softwareDecides what the Station does. It is written in Mentl, a language I built: its rule, never reach the internet, is in the code, and the compiler checks it through every function the decision calls.

Why it matters

AI now helps write the software that runs machines. C and C++, the languages most of it is written in, can't check what that software will never do.

Batteries, flywheels and flight controls run on code that people test and review, and then trust.

The hard tech

The rule is part of the code, and the compiler checks it through every call.

You write the rule into the code: this never touches the internet, this never writes a file, this never allocates memory.

The compiler checks the rule through every function the code calls. Break it, and the program won't build.

Seven months and 2,600 commits since March. The compiler is written in Mentl and compiles itself. Open source: github.com/ampactor-labs/mentl

What Mentl code looks like

Five operators draw the shape of a program. The compiler checks each rule along that shape.

let l = saw |> rig.dark(300.0) |> soft_clip|>in sequence: the sawtooth, the filter, the clipper
let (echoed, roomed) = dry <| (rig.echo, rig.room)<|one sample to the echo and to the room; shared, so the two cannot race
let l = ((echoed) >< (dry)) |> mix(0.35)><two signals side by side, then mixed
{ prev => a * x + (1.0 - a) * prev } <~ delay(1)<~feedback: this sample from the last one; the memory is allocated once
handler rack = spectral_flux_distort ~> limiter_at(0.6)~>the handler: what the sound goes through, named once

The controller's rule is on its decision: with !Alloc + !Network + !Filesystem + !WASI + !Trap. The compiler checks it through every function the decision calls, and the copy that read a price online did not build.
