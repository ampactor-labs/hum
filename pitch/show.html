The hard tech

Mentl proves what software can never do.

You write a rule into the code, such as "this never touches the internet" or "this never writes a file".

The compiler checks the rule through every function the code calls. Break it, and the program won't build.

Seven months and 2,600 commits since March. The compiler is written in Mentl and compiles itself. Open source: github.com/ampactor-labs/mentl

What Mentl code looks like

Five operators draw the shape of a program. The compiler checks each rule along that shape.

fn read(hz) = hz |> fast|>pipe: one stage feeds the next
fn fork(hz) = (hz) <| (fast, slow)<|split: one value goes to two branches
fn pair(a, b) = (a |> fast) >< (b |> slow)><parallel: two branches run side by side
fn trend(hz) = ((prev) => prev + hz) <~ Delay(1)<~feedback: each step sees the step before
fn act(hz) with !Network = spin(hz) ~> flywheel~>handler: names who answers the request

The last line carries a rule, with !Network: if anything act calls could reach the network, the compiler refuses to build it. Four of the operators come from Faust, the audio language; ~> is Mentl's own.
